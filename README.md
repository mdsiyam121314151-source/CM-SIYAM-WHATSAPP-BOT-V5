# RJ-siyam whatsapp-botV5

**Author:** 𝐑𝐉 𝐬𝐢𝐲𝐚𝐦

**Version:** 5.0.0

## Features

- WhatsApp Phone Number Pairing Code Login
- Persistent Session
- Command Handler
- Group Support
- Private Inbox Support
- Owner Permission
- Bot Admin Permission
- Group Admin Permission
- User Permission
- Multiple Bot Modes
- Command Aliases
- Author Validation

## Requirements

- Node.js 20+
- npm

## Installation

```bash
npm install
```

## Environment Setup

মূল ফোল্ডারে `.env` নামে ফাইল তৈরি করো।

```env
BOT_PHONE_NUMBER=8801XXXXXXXXX
OWNER_NUMBER=8801XXXXXXXXX
BOT_PREFIX=.
LOG_LEVEL=info
MESSAGE_MODE=all
```

## Start Bot

```bash
npm start
```

## WhatsApp Login

1. Bot চালু করো।
2. Terminal থেকে Pairing Code নাও।
3. WhatsApp খুলে Linked Devices-এ যাও।
4. Link with phone number নির্বাচন করো।
5. Pairing Code প্রবেশ করাও।
